Library Bridge — native macOS recovery utility for Native Instruments libraries.
Users: musicians migrating macOS or computers while keeping large external libraries.
Job: inspect actual files, recover valid registrations, retain authentic receipts on disk,
show verifiable differences before downloading, and distinguish content from plugins/apps.
Composition: operating work surface: source folder → scan → inspect rows → review plan → repair.
Native AppKit with a light Native Access inspired visual language: bundled Roboto,
off-white canvas, charcoal text, restrained blue accents, flat rectangular controls,
text tabs and fine horizontal rules. Primary actions use charcoal. Preserve native
keyboard and Accessibility semantics. Independent Native FixTool identity; no NI logos.
Polish and English. Real data only, explicit capability/version gates, no invented savings.
Must support empty, busy, offline, permission denied, unsupported version, partial, cancelled,
conflicting identity, unowned content, missing descriptor, pending verification, and success.
No telemetry or NI credentials. All reports and portable receipts stay local.

0.2 update flow: official catalogue → optional SSD comparison → reviewed UPDATE queue → NI confirmation. Distinguish full content size from estimated piece transfer. Never label a comparison as an installation. Preserve existing NI jobs and refuse duplicate products.

0.3 UX: Native FixTool is the user-facing name. Home offers Naprawa / Aktualizacje / Przeniesienie with the user-approved descriptions. Repair filters use Wszystkie / Zainstalowane / Dostępne / Problemy, each with a visible explanation. Folder selection automatically loads the relevant read-only list. Selecting and reviewing are separate from starting writes. Keep technical details in History/help/context menus. Do not move user presets out of Documents.
